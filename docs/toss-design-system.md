# 토스 (Toss) Design System Reference

> 이 파일은 토스 디자인 시스템(TDS) 핵심 토큰 참조 문서입니다.
> my-link-hy 프로젝트의 디자인 기준으로 사용됩니다.

## 핵심 색상 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| blue-500 | #3182F6 | Primary CTA, 링크, 강조 — 화면당 하나 |
| blue-50  | #E8F3FF | Brand weak 배경, 칩 배경 |
| grey-900 | #191F28 | Primary 텍스트 |
| grey-700 | #4E5968 | Secondary 텍스트 |
| grey-400 | #B0B8C1 | Disabled 텍스트, 보더 |
| grey-200 | #E5E8EB | 기본 divider/보더 |
| grey-100 | #F2F4F6 | Secondary 표면 |
| white    | #FFFFFF | 기본 배경 |

## 타이포그래피

- 폰트: Pretendard Variable (TPS 대체)
- display-2: 40px / Bold 700 / -0.02em
- h1: 28px / Bold 700 / -0.02em
- title-1: 18px / Semibold 600 / -0.01em
- body-1: 17px / Regular 400 / -0.005em
- body-2: 15px / Regular 400 / -0.005em
- label-m: 15px / Semibold 600 / -0.005em
- caption: 12px / Medium 500

## 라운드

- radius-xl: 16px (카드)
- radius-l: 14px (L버튼)
- radius-m: 12px (입력, M버튼)
- radius-full: 999px (Pills, chips, CTA)

## 간격

- 화면 outer padding: 24px
- list-row 간격: 16px
- 밀접 요소 사이: 8px

## 규칙

- 강조색은 blue-500 단 하나, primary CTA는 화면당 하나
- 그라디언트 사용 금지 (보호 그라디언트 등 3가지 예외만 허용)
- 텍스트는 해요체
- 그림자 없음 (floating/modal만 허용)
- 버튼은 "일어날 일을 직접 말한다" (송금하기, 다음, 시작하기)
