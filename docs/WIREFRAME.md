## 3. 반응형 뷰포트 처리 기준

1. **초소형 모바일 (`≤ 400px`, iPhone SE / 갤럭시 S8)**
   - 카드 좌우 패딩: `24px` → `16px`로 축소
   - 액션 버튼 높이: `52px` → `48px`로 최적화
   - 링크 카드 제목/설명: 너비 초과 시 자연스러운 `...` 말줄임 처리
2. **표준 모바일 및 태블릿 (`401px ~ 840px`)**
   - 가로 너비 390px 고정, 화면 중앙에 안정적으로 배치
3. **데스크톱 (`≥ 841px`)**
   - 화면 정중앙에 스마트폰 비율의 카드가 놓여 깔끔하고 집중도 높은 링크트리 경험 제공
