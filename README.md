# my-link-hy 🚀

> **Next.js 기반의 감각적이고 반응형인 개인 프로필 링크 웹 애플리케이션**

## 📌 주요 기능
- **개인 프로필 카드**: 프로필 이미지, 상태 표시, 자기소개 및 태그
- **빠른 액션 버튼**: 이메일 연락하기 및 링크 연결
- **반응형 디자인**: 모바일 및 데스크톱 완벽 지원

## 🛠️ 시작하기 (Development)

개발 서버 실행:

```bash
npm run dev
# 또는
yarn dev
# 또는
pnpm dev
# 또는
bun dev
```

[http://localhost:3000](http://localhost:3000) 접속하여 결과를 확인하실 수 있습니다.
